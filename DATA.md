# Data

## What is released, and where

| | Location |
|---|---|
| Paired SAE/dialect prompts | HuggingFace, gated: https://huggingface.co/datasets/Minguinho-zeze/dialect-penalty-t2i |
| Per-prompt experiment outputs | This repo, `results/experiment_outputs/` |
| Aggregate tables and figures | This repo, `results/` |
| Stage 3 training inputs | This repo, `stage3_mitigation/original_dataset/` |

Generated images are **not** released. Third-party model weights and source datasets are not
redistributed; fetch them from their original distributors.

## Download

```bash
hf auth login                    # request access on the dataset page first
python common/fetch_data.py      # -> prompts_dataset/, foreign_languages/
```

The HuggingFace release uses a normalized schema (`sae`, `aave`, …); `fetch_data.py` maps it back to
the column names the experiment scripts expect (`standard_prompt`, `AAVE_prompt`, …).

Stage 3 needs no download: its inputs are checked into `stage3_mitigation/original_dataset/`.

## Schema

`toxic_prompts.csv` (2,216 rows) and `benign_prompts.csv` (2,400 rows):

| Column | Description |
|---|---|
| `category` | Risk category (toxic) or content category (benign) |
| `standard_prompt` | Standard American English |
| `AAVE_prompt` … `JamE_prompt` | Dialect translations |
| `raw_caption` | Source COCO caption (benign only) |

Toxic spans 14 risk categories (up to 200 each; prompts the translator refused are excluded, so
counts are uneven). Benign spans 6 content categories, 400 each.

The Stage 3 copy in `stage3_mitigation/original_dataset/` is the same data with an `SAE_prompt`
column and the first character upper-cased (the `first_upper` normalization also applied before
filter scoring). Train/val splits and the balanced and imbalanced variants are regenerated by
`prepare_data.py`, `prepare_balanced.py`, and `prepare_imbalanced.py`.

Cross-lingual files (`{German,Arabic}_translated_{toxic,benign}_prompts.csv`) use
`category`, `english`, `translated`.

## Provenance

**Toxic prompts** derive from T2I-RiskyPrompt; `standard_prompt` is taken verbatim from it, and the
dialect columns are our translations. That repository carries no explicit license: we redistribute
with attribution for non-commercial safety research, and will remove on request by the original
authors. Their category-wise banned keyword lists are also the basis for our keyword-filter
baseline. Citation and links are in the [README](README.md#attribution).

**Benign prompts** are sampled from COCO Captions val2017 (CC BY 4.0) and expanded into T2I prompts
following the PromptGuard procedure.

**Dialect selection and translation** follow EnDive, using a GPT-family model instructed to preserve
visual description and safety valence while changing only dialectal grammar and lexicon. Reproduce
with `data_construction/translation_to_dialect_riskyprompt.py` and `..._t2i_coco.py`.

## Models

| Component | Identifier |
|---|---|
| NSFW text classifier (NSFW-T) | [`michellejieli/NSFW_text_classifier`](https://huggingface.co/michellejieli/NSFW_text_classifier) |
| Mitigation backbone | [`distilbert/distilbert-base-uncased`](https://huggingface.co/distilbert/distilbert-base-uncased) |
| Mitigation classifiers (ours, released) | [`...-guardrail-erm-balsampling`](https://huggingface.co/Minguinho-zeze/dialect-penalty-t2i-guardrail-erm-balsampling), [`...-guardrail-groupdro`](https://huggingface.co/Minguinho-zeze/dialect-penalty-t2i-guardrail-groupdro) |
| T2I generator | [`CompVis/stable-diffusion-v1-4`](https://huggingface.co/CompVis/stable-diffusion-v1-4) |
| Safe Latent Diffusion | [`AIML-TUDA/stable-diffusion-safe`](https://huggingface.co/AIML-TUDA/stable-diffusion-safe) |
| CLIP encoder | [`openai/clip-vit-large-patch14`](https://huggingface.co/openai/clip-vit-large-patch14) |
| Multi-head image evaluator | Projection heads by Qu et al., from [Unsafe Diffusion `checkpoints/multi-headed`](https://github.com/YitingQu/unsafe-diffusion/tree/main/checkpoints/multi-headed), over the CLIP encoder above |
| ShieldGemma 2 | [`google/shieldgemma-2-4b-it`](https://huggingface.co/google/shieldgemma-2-4b-it) |

Q16 and the LAION CLIP-based NSFW detector are fetched by `common/prepare_evaluator_weights.py`.
PromptGuard and Latent Guard are reimplemented from their papers; the Latent Guard checkpoint and
its CoPro concept cache are not redistributed, and neither are the multi-head projection heads,
which are Qu et al.'s own trained weights.

## Validation

Translation quality was checked by a round-trip audit (SAE → dialect → SAE with an independent
back-translator, scored by three independent scorers). Code is in `extended_analysis/`, summaries in
`results/backtranslation_audit/`.

That audit checks content preservation. It is **not** native-speaker validation: the translations
were not verified for naturalness, representativeness, or stereotyping risk, and should be treated
as a controlled perturbation for auditing filters rather than as authoritative samples of any speech
community. Image-level labels rest on automatic classifiers without human validation. The
cross-lingual data is a limited two-language replication, not a general cross-lingual claim.

The toxic prompts are filter inputs only. Using them to generate harmful content is out of scope and
contrary to this release.
